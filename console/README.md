# Firenook console

The emulator's own UI. A client-only React application, built with Vite and
embedded into the engine binary, served under `/console` on the Emulator UI
port. Every asset and API call is same-origin with the page, so the console
works whatever scheme the UI was opened with.

Status: the stack, the shell, the overview and the Console API's first route
are in place; the service sections are placeholders that say so. The Google
Emulator UI keeps answering at `/` on the same port until every section has
landed.

## Working on it

```
npm ci --prefix console
npm run dev --prefix console       # http://127.0.0.1:5173/console, proxies the API to a running engine
FIRENOOK_UI_ORIGIN=http://127.0.0.1:34000 npm run dev --prefix console   # a non-default UI port
npm run build --prefix console     # console/dist, read at runtime by debug engine builds, embedded by release builds
```

Checks, all run in CI:

```
npm run check --prefix console         # TypeScript
npm run lint --prefix console          # oxlint
npm run format:check --prefix console  # oxfmt
npm run test --prefix console          # Vitest + Testing Library
npm run budget --prefix console        # first-route gzip budget from the Vite manifest
npm run test:e2e --prefix console      # Playwright against a real engine (target/debug/firenook) and a synthetic project
cargo test -p firenook-console-front   # Console API tests; also writes src/api/generated/*.ts
```

## Layout

```
src/routes/            file-based routes (routeTree.gen.ts is generated by the Vite plugin and committed)
src/features/          one folder per section as it lands
src/components/        the shell, the command palette, shared pieces
src/api/               fetch client, query options, generated Console API types (never hand-edited)
src/lib/               query client, UI store, the section registry
e2e/                   Playwright suite and the engine launcher it uses
scripts/               the bundle budget
```

The Rust side is `crates/console-front`: the Console API handlers, the
embedded assets and their cache policy. Rust types are the contract; ts-rs
exports them into `src/api/generated`.
